# 个人助教定位与账号数据治理推进记录

日期：2026-10-23

产品范围调整：不再建设考试身份绑定、教师端或考试 roster。AlgoSage 定位为与学生 HUST 账号关联的个人算法学习助教；继续保留服务端分级辅导和输出审核，避免直接代写完整作业。

本轮实现：

- 注销账号前删除该学生的全部个人会话、后端模型历史、附件原件、附件记录和反馈，只保留认证库中的最小关闭状态。
- 聊天、认证、安全状态 SQLite 及 WAL/SHM 文件启动时强制服务进程属主可读写，运行目录与附件目录强制 `0700`。
- 普通消息加入服务端长度上限，默认 `SAGE_MAX_INPUT_CHARS=20000`，超长输入在模型调用前拒绝。
- 新增按学生 principal 的每日请求计数，默认 `SAGE_DAILY_REQUESTS_PER_STUDENT=100`，同一学生跨会话共享限额。
- 新增运行时 Origin 白名单中间件，生产通过 `SAGE_ALLOWED_ORIGINS` 注入；默认仅允许本机开发地址。
- 新增显式 Cookie 策略：`CHAINLIT_COOKIE_SAMESITE` 默认 `strict`，生产 HTTPS 下设置 `SAGE_SECURE_COOKIES=true`。

回归覆盖运行数据权限、注销级联删除、按账号限额、超长输入、Origin 白名单与 Cookie 配置。全量离线测试和 Chainlit E2E 通过。

第二批清理：

- 学生端移除学习保护模式开关和教师重置入口；普通用户只能选择 Provider / 模型。
- 注销账号同时删除学习保护状态快照和每日请求计数。
- 登录元数据在未上传头像时不再请求头像接口，避免无头像账号的控制台 404。
- 新增 GitHub Actions 离线测试与 Chainlit E2E 工作流。
- 新增 Dockerfile、Compose、`.dockerignore` 和部署说明；容器以非 root 用户运行，运行数据写入卷。
- 新增 `requirements.lock`，CI 和生产镜像使用固定依赖集；测试与 E2E 纳入 GitHub Actions。
- 修正注销清理时学习保护状态分区，按运行服务端的实际分区删除，而不是固定使用占位分区。
- 注销时匿名化认证库中的昵称、教育邮箱和密码哈希，并清空验证码记录。
- 新增跨学生共享的全平台每日请求上限 `SAGE_GLOBAL_DAILY_REQUESTS`，默认 1000；达到上限后所有学生当日暂停新请求。

第三批修复：

- 审核步骤内部名称改为稳定 ASCII 标识，避免 Chainlit 旧头像接口拒绝中文/emoji；前端仍显示中文业务名称。
- 启动器为历史会话中的旧版审核步骤头像请求增加兼容回退，消除控制台 400。
- 浏览器复核收起态新建对话保持侧栏收起；新建页与既有会话页的输入框和内容基准宽度一致；深浅色切换后控制台无错误。
