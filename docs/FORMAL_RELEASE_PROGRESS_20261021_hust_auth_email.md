# HUST 学生登录与邮件验证实现记录

日期：2026-10-21

学生认证新增 `local` 和 `hust` 两种模式。`local` 保留原有浏览器工作区；`hust` 启用学号密码登录。账号、密码哈希和一次性验证码存放在独立的 `EG_AUTH_DB_FILE` 中。

注册页接受昵称、学号和密码。学号默认匹配 `U202[0-9]1[0-9]{4}`，邮箱派生为 `学号@hust.edu.cn`。验证码六位、10 分钟有效、最多尝试 5 次；同一账号 60 秒内不能重发，账号和来源分别有小时上限。验证码只保存 HMAC 哈希，邮件失败时不占用重发窗口。密码使用 Argon2id。

登录走 Chainlit 原生密码登录表单，用户名是学号。成功后的服务器 principal 是 `student:<学号>`，历史、Provider 选择和安全预算按该 principal 隔离。已有匿名浏览器历史不自动并入实名账号。

忘记密码页面通过学号请求教育邮箱验证码。未知账号不发信但消耗相同的请求限额，响应形态保持一致。重置成功后账号的 session version 递增，旧学生登录 Cookie 会被服务端拒绝。

开发环境可用 `EG_EMAIL_SENDER=outbox`，邮件写入权限受限的 `.examguard/dev-outbox`。生产环境配置 `smtp`、SMTP 主机、账号、发件人和 TLS。验证码不进入日志。

新增隔离回归覆盖格式校验、验证码确认、重发限制、错误验证码、登录失败锁定、密码重置、未知账号通用响应、outbox 权限和 HTTP 注册/重置路由。
