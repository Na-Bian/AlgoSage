# 反馈越权修复记录

日期：2026-10-21

Chainlit 默认的 `/feedback` 接口只做登录认证，数据层写入时拿不到当前用户，因此无法判断反馈目标是否属于调用者。这个版本在应用启动时替换默认的 PUT 和 DELETE 路由，并新增两条受限数据层路径：

- 更新反馈前，同时校验步骤所在线程、反馈声明的线程和当前用户是否一致。
- 删除反馈前，先找到反馈所属线程，再校验线程作者。
- 跨用户写或删返回 403；目标不存在时分别按 400 或 404 返回，不泄露可操作状态。

回归覆盖数据层和真实 FastAPI 路由：Bob 不能创建、修改或删除 Alice 的反馈；Alice 可以正常创建和删除。全量离线测试通过。
