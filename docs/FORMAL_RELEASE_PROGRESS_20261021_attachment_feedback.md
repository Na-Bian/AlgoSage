# 正式版推进记录：附件历史与反馈持久化

日期：2026-10-21

本轮补齐正式版路线图第 3 项中 Chainlit 前端可见数据的持久化缺口。

- `ChatDataLayer` 新增 `elements` 与 `feedbacks` 表。上传附件的元数据、原始字节、线程归属和反馈值/评论在重启后恢复。
- 附件原件写入数据库旁的私有 `elements/` 目录；下载走新的 `/project/element/{thread_id}/{element_id}/content` 端点，先做线程作者校验，再返回受限文件响应。
- 删除会话时同步删除 `elements`、`feedbacks` 记录和附件文件，避免孤儿私有文件；`:memory:` 测试实例使用临时元素目录并在关闭时清理。
- 回合数据返回时合并反馈状态和持久化附件 URL，前端历史不再依赖浏览器临时上传对象。
- 存储回归覆盖上传/反馈写入、重启恢复、下载路径、反馈删除和会话删除后的文件清理。
- 浏览器验收使用 mock 实例完成：DOCX 上传返回 200，页面刷新后附件仍可见且私有端点返回 37,053 字节；反馈对话框提交返回 200，刷新后仍为选中状态且评论入库。结果与截图保存在本地维护记录 `ExamGuard第3项验收_20261021/`，不包含用户私有数据。
- 全量离线回归为 364 项测试（含 81 个子测试）通过；端到端冒烟覆盖保存恢复、跨工作区隔离、跨目录重启、Provider 持久化、考试门控和无密钥泄漏。

边界：这一步解决本地 Chainlit 数据层的持久化缺口。真实考试身份绑定仍未完成，也不能替代发布门槛要求的冻结评测与部署验收。
