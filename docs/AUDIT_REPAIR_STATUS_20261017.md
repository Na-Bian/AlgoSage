## 仍须如实保留的边界

1. 本轮未调用真实 LLM API。真实模型辅助正确率、语义泄漏率、误拒率及组件实际贡献需要重新实验，并做人工 rubric 标注；mock 数字不能替代这些结论。
2. 规则和 AST 检测不覆盖一切语言、自然语言改写或语义等价攻击。LLM Judge 也不是可信真值。
3. 已认证用户可跨聊天关联预算；匿名新会话没有可信身份，不能保证跨新身份累计防护。演示环境变量也不能替代教师角色认证。
4. SQLite 为保证一致性在整个回合持有写事务，写入串行；课程规模可用，部署吞吐与等待时间仍须另测。Python 自定义同步假后端不能被强制打断，生产适配器按剩余时间设置网络超时。
5. 教师页仍是开发 smoke 工具，正式 Harness 与质量复核使用离线记录；没有把它包装成已完成的完整教师后台。
6. 原 heldout 已参与审计查看；调参后正式评测应建立新的冻结留出集。

已经运行中的旧 `run_app.py` 进程不会自动加载这些模块改动，需重启对应服务后生效。本轮未关闭原有运行进程；E2E 使用独立临时端口并在验证后退出。
